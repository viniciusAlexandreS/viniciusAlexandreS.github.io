Seção 3-Glossário tecnico

HTML
Linguagem de marcação utilizada para estruturar páginas web.
CSS
Linguagem de estilo utilizada para definir a aparência das páginas web.
JavaScript
Linguagem de programação utilizada para adicionar interatividade às páginas web.
pode ser usado tanto no beckend e no frontend
URL
Endereço web
Identificador de recursos uniforme, utilizado para acessar recursos na web.
HTTP
Protocolo web
Protocolo de comunicação utilizado para transferir dados na web.
DOM
Modelo de Objeto de Documento, utilizado para representar a estrutura de uma página web.
API
Interface de comunicação entre sistemas.
Permite integração entre aplicações.
DNS
Serviço de nome de domínio, utilizado para traduzir nomes de domínio em endereços IP.
